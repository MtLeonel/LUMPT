Como instalar no Windows (3 passos)
  1. Extraia o ZIP: botão direito no arquivo → Extrair tudo… (não abra de dentro do ZIP).
  2. Na pasta extraída, dê dois cliques em ABRIR-LUMPT.bat. O LUMPT abre em uma janela própria.
  3. Opcional: rode CRIAR-ATALHO.bat para ter o ícone na Área de Trabalho.

Se o Windows SmartScreen avisar, clique em Mais informações → Executar assim mesmo. Os arquivos são só HTML, CSS e JavaScript e podem ser conferidos no Bloco de Notas.

O pacote do Windows não é um instalador .exe: ele abre o app pelo Microsoft Edge ou Chrome já instalados no computador.

Dúvidas

Antes de começar

O LUMPT é para quem nunca programou?

Sim. A proposta é ser acessível para iniciantes, com lições em etapas, exemplos e explicação dos erros. Quem já tem experiência também encontra desafios e o laboratório para praticar.

Qual a diferença entre as versões?

No navegador você usa sem instalar nada. A versão de Windows é um pacote ZIP que funciona offline, e a de Android é um APK. Confira a compatibilidade do seu aparelho antes de instalar.

Meu progresso fica salvo?

Sim, no próprio navegador ou aparelho que você usa. Por isso, o progresso não é compartilhado automaticamente entre dispositivos diferentes.

O assistente de IA e todos os recursos estão disponíveis?

A disponibilidade de cada função, como a IA, depende da configuração da versão que você está usando. Algumas funções precisam de conexão com a internet.

O download do Windows abriu em branco. E agora?

Isso acontece quando o index.html é aberto de dentro do ZIP. Extraia tudo (botão direito → Extrair tudo…) e abra o ABRIR-LUMPT.bat da pasta extraída. Se preferir, use “Abrir no navegador”.

Como continuar aprendendo depois?

Pratique um pouco todos os dias, teste os exemplos, leia as mensagens de erro com atenção e tente entender cada resultado. Constância vale mais do que tentar aprender tudo de uma vez.
