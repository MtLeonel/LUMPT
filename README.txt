Instalador do LUMPT

1. Execute o arquivo install_lumpt.cmd para iniciar a instalação.
2. O instalador abrirá uma janela simples para escolher a pasta de instalação.
3. Ele copia a pasta completa do programa LUMPT para a pasta escolhida, cria um atalho na área de trabalho e também um atalho no menu Iniciar.
4. Funciona com Windows 7 e versões mais novas.
5. O pacote é autônomo e instala o executável principal, os arquivos internos e os componentes auxiliares do programa.
